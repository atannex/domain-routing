# Upgrade guide

Breaking changes come only in major versions. Deprecated APIs are marked for at least one minor release before they are removed, and each removal is listed here.

The stable API is: the `DomainRouting` facade and manager, `Sites\Site`, `Resolution\SiteMatch`, `Resolution\SiteContext`, `Contracts\*`, `Hosts\ResolvedHost`, the helpers, config keys, events, console command names, `Attributes\Site` and `Testing\*`. Classes marked `@internal` may change in any release.
